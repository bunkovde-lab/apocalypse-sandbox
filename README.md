# Apocalypse Sandbox (рабочее название)

2D-песочница выживания в духе Terraria на Godot 4.3+: строим убежище, спасаем выживших, спускаемся от руин к технобазе корпорации.

Полное ТЗ: [docs/GDD.md](docs/GDD.md).

## Запуск

1. Установить Godot 4.3 или новее.
2. Импортировать папку проекта (файл `project.godot`) и нажать F5. Игра стартует с главного меню.

## Управление

| Клавиша | Действие |
| --- | --- |
| A/D, Пробел, S | ход, прыжок (на лестнице вверх), вниз по лестнице |
| ЛКМ / ПКМ | копать или бить / ставить блок, надеть броню, лечиться |
| 1-0, колесо | выбор ячейки быстрой панели |
| E | действовать: дверь, кровать, генератор, спасти выжившего, алтарь босса |
| Tab | инвентарь и крафт |
| M | карта мира (туман войны) |
| Esc | пауза: сохранить, звук, выход в меню |
| F5 | быстрое сохранение |

## Как пройти

Прогресс идёт по боссам (флаги `boss_1`..`boss_9`): каждый открывает рецепты и подземный слой.
Приманку для босса куёте в кузнице, ставите на его алтарь и жмёте E.
Порядок: Главарь мародёров → Королева-матка → Командир и Хозяин пустоши → Страж корпорации, Король шахты, Мозг гнезда → Директор → «Ядро». После «Ядра» выбираете концовку.
Еда и вода героя не нужны: они влияют на стабильность убежища (см. раздел 10 ТЗ).

## Автотесты

`tools/test.sh [stage1 ... stage9]` запускает проверки без окна (около 700 проверок: мир, крафт, бой, убежище, боссы, слои, финал, сохранения).
Скриншоты: `tools/shot.gd` через `xvfb-run`.

## Структура

| Папка | Назначение |
| --- | --- |
| `scenes/` | меню и игра |
| `scripts/world`, `player`, `enemies`, `shelter`, `survivors`, `core`, `ui` | код по системам (раздел 15 ТЗ) |
| `data/` | блоки, предметы, рецепты, враги, боссы, слои, баланс в JSON |
| `tests/` | автотесты по этапам |
| `docs/` | ТЗ |

## Состояние

Этапы 0–9 из раздела 16 ТЗ реализованы: от руин до реактора, 9 боссов, события, сохранения, звук, свет, карта.
Графика пока из цветных блоков-заглушек, звуки процедурные: их можно заменить готовыми ассетами.
