# Apocalypse Sandbox (рабочее название)

2D-песочница выживания в духе Terraria на Godot 4.3+: строим убежище, спасаем выживших, спускаемся от руин к технобазе корпорации.

Полное ТЗ: [docs/GDD.md](docs/GDD.md).

## Запуск

1. Установить Godot 4.3 или новее.
2. Импортировать папку проекта (файл `project.godot`) и нажать F5.

## Структура

| Папка | Назначение |
| --- | --- |
| `scenes/` | сцены Godot |
| `scripts/world`, `player`, `enemies`, `shelter`, `survivors`, `events`, `core`, `ui` | код по системам (раздел 15 ТЗ) |
| `data/` | предметы, рецепты, враги, биомы в ресурсах/JSON |
| `assets/` | графика и звук (проверять лицензии) |
| `docs/` | ТЗ и заметки |

## Дорожная карта

Этапы 0–9 описаны в разделе 16 ТЗ. Текущий этап: **0. Подготовка**.
